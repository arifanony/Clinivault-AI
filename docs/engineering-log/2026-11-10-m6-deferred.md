# M6 scope check — deferred, no measured retrieval weakness

> Only log problems that taught us something or changed an implementation
> decision. No trivial syntax mistakes.

## Date

2026-11-10

## Where It Happened

Retrieval stage (`retrieval/`, `embedding/`) and the frozen 46-case
benchmark — read-only. No retrieval, embedding, chunking, Top-K, or
evaluation code was touched in this unit.

## What We Expected

Per §M6 of the M1–M7 guide: run a one-variable retrieval experiment
(hybrid, rerank, BM25, Top-K) only if M1–M5 show a specific, measured
retrieval weakness. Otherwise write this deferred log and change nothing.

## What Actually Happened

**OBSERVED:** The weaknesses on record were measured against the old
hash baseline and have already been answered. The ranking investigation
found a T2D-006 q2 near miss (relevant chunk at rank 6, one below the
Top-5 cutoff) and a T2D-009 q2 statins lexical-coverage gap (relevant
chunks at ranks 21/42/98); the controlled comparison confirmed both
were narrow and that both counterfactuals traded those fixes for
broader regressions. The response was M1: production retrieval is now
raw `intfloat/e5-small-v2` at frozen Hit@1 20/46, Hit@5 36/46, MRR
0.5583 (vs hash 12/46, 26/46, 0.3601).

**OBSERVED:** M2–M5 changed no retrieval math. Verified again in this
unit: `python -m clinivault_ai.evaluation.benchmark --provider hash`
reproduces the frozen hash numbers exactly
(Hit@1=12/46 Hit@5=26/46 MRR=0.3601), and no M2–M5 diff touches
`retrieval/`, `embedding/`, chunking, or Top-K paths.

**OBSERVED:** No post-M1 failure-class analysis of E5's residual
misses (10/46 outside Hit@5, 26/46 outside Hit@1) exists. Nothing on
record attributes those misses to a mechanism that hybrid retrieval,
reranking, BM25, or a Top-K change would fix, as opposed to label
scope, chunking, or query phrasing.

**INFERENCE:** There is no specific measured weakness for an M6
experiment to target. Running hybrid/rerank/BM25/Top-K now would be an
unmeasured multi-variable change — exactly what §M6 forbids. M6 is
therefore deferred with zero code, test, artifact, or benchmark-label
changes.

Docs only: this log. Production retrieval, benchmark, labels,
